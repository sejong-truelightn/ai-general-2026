직선부터 시작하는 이유

  • 가장 쉽습니다. 찾을 숫자가 두 개(a, b)입니다.
  • 해석이 됩니다. 광고비를 1 늘리면 매출이 2 오른다는 식으로 설명할 수 있습니다.
  • 더 복잡한 방법의 기초가 됩니다. 딥러닝의 각 층도 선형 계산에서 시작합니다.

직선 모델의 한계

세상의 관계가 진짜로 직선인 경우는 많지 않습니다. 그런데도 직선부터 배우는 이유는, 좁은 범위에서는 직선으로 근사가 꽤 잘 되고 결과를 사람이 읽을 수 있기 때문입니다.

오늘의 문제

광고비를 얼마 쓰면 매출이 얼마나 오를까

어떤 회사가 몇 년 동안 광고비와 매출을 기록해 두었습니다.

맞혀야 할 매출이 실수값이므로 회귀(regression) 문제입니다.

이 데이터로 답하고 싶은 질문들

  • 광고비와 매출 사이에 관계가 있기는 한가?
  • 있다면 얼마나 강한가?
  • 셋 중 어디에 투자하는 게 가장 효과적인가?
  • 500만 원을 쓰면 매출이 얼마나 오를지 예측할 수 있는가?

먼저 TV 광고비 하나만 가지고 매출을 예측해 봅니다.

같은 광고비를 써도 매출은 매번 조금씩 다릅니다. 경기, 경쟁사, 우연 같은 요인이 있기 때문입니다. 그래서 정확한 하나의 값이 아니라 평균적인 값을 맞히는 것이 목표입니다.

시작하기 전에

산점도로 관계 보기

x와 y를 점으로 찍은 그림을 산점도라고 합니다. 점들이 놓인 모양을 보면 관계가 있는지 알 수 있습니다.

① 양의 상관관계

점들이 오른쪽 위로 모여 있습니다. x가 늘면 y도 늘어납니다. 이것을 양의 상관관계라고 합니다. 직선을 그어 볼 만합니다.

② 상관관계 없음

점들이 흩어져 있습니다. 여기에 직선을 그어도 의미가 없습니다.

③ 음의 상관관계

점들이 오른쪽 아래로 내려갑니다. x가 늘면 y는 줄어듭니다. 이것을 음의 상관관계라고 합니다. 기울기가 음수인 직선으로 예측할 수 있습니다.

직선 ŷ = ax + b

모양이 바뀌는 동안 숫자는 소수 둘째 자리까지 그대로입니다. 점을 끌어서 옮기면 숫자가 바뀌고, 처음과 달라진 숫자는 빨간색으로 표시됩니다.

STEP 1

모델의 형태를 정한다: 직선

중학교에서 배운 일차함수와 같은 식입니다. 부르는 이름만 다릅니다.

ŷ = ax + b ŷ = β₀ + β₁x라고도 씁니다. 같은 식입니다.
x · 입력

TV 광고비
모델에 넣는 값

다른 이름 — 특징(feature), 독립변수, 예측변수

y · 정답

실제 매출
과거에 기록된 값

다른 이름 — 라벨(label), 종속변수, 목표값

a, b · 찾아야 할 값

기울기와 절편
데이터로 정하는 값

다른 이름 — 계수(coefficient), 파라미터

b(절편) — 광고를 하나도 안 했을 때의 매출입니다. 0일 수도 있지만, 어느 정도 자리 잡은 회사라면 보통 0보다 큽니다.

a(기울기) — 광고비를 1 늘릴 때 매출이 오르는 정도입니다. 광고가 아무 소용이 없다면 a = 0이 나와야 합니다.

STEP 2

얼마나 잘 맞혔는지 숫자로 정의한다

컴퓨터가 계산하려면 숫자로 된 채점 기준이 필요합니다.

① 오차 = 실제값 − 예측값

eᵢ = yᵢ − ŷᵢ

데이터 한 건마다 오차 e(error)가 하나씩 생깁니다. 이걸 잔차(residual)라고 부릅니다. 완벽하게 맞혔다면 모든 오차가 0입니다.

② 그런데 그냥 더하면 안 된다

오차는 양수일 수도, 음수일 수도 있습니다. +5만큼 틀리고 −5만큼 틀렸는데 그냥 더하면 0이 되어 완벽하게 맞힌 것처럼 보입니다.

(+5) + (−5) = 0  ❌

③ 그래서 제곱해서 더한다

RSS = Σ ( yᵢ − ŷᵢ )² residual sum of squares · 잔차 제곱합

제곱하면 부호가 사라져 크기만 남습니다. (+5)² + (−5)² = 50이므로 틀린 만큼 값이 커집니다.

MSE(평균 제곱 오차)는 RSS를 데이터 개수 n으로 나눈 값입니다. MSE = RSS / n

STEP 2

RSS를 읽는 법

RSS = Σ ( yᵢ − ŷᵢ )²
  • 제곱을 더했으므로 음수가 될 수 없습니다.
  • RSS = 0이면 모든 점을 완벽하게 맞혔다는 뜻입니다.
  • 따라서 작을수록 좋은 모델입니다.
  • n으로 나눈 평균은 MSE(평균 제곱 오차)입니다.

STEP 2 정리: RSS와 MSE는 예측이 얼마나 틀렸는지 재는 기준이고, 최소제곱법(least squares)은 그것을 줄이는 a, b를 찾는 방법입니다. MSE로 해도 답은 같습니다.

제곱과 절댓값

왜 제곱을 쓸까? 절댓값은 안 될까?

절댓값도 쓸 수 있습니다. 다만 성질이 다릅니다.

제곱을 쓰면

크게 틀린 것에 훨씬 큰 벌점을 줍니다. 2만큼 틀리면 벌점 4, 4만큼 틀리면 벌점 16입니다. 두 배 틀리면 벌점은 네 배가 됩니다.

장점: 크게 빗나가는 예측을 줄여 줍니다.
단점: 이상치(outlier) 하나에 직선이 끌려갈 수 있습니다.

절댓값을 쓰면

2만큼 틀리면 벌점 2, 4만큼 틀리면 벌점 4로 틀린 만큼 비례합니다.

장점: 이상치의 영향을 덜 받습니다.
단점: 계산이 까다롭고 한 번에 풀리는 공식이 없습니다.

제곱을 쓰는 실용적인 이유

제곱을 쓰면 정답을 계산하는 공식이 존재합니다. 선형 회귀는 한 번에 풀리는 몇 안 되는 머신러닝 모델입니다.

제곱과 절댓값

제곱을 쓰는 이유 자세히 보기

슬라이더로 오차 e를 움직이면서 각 점에서의 접선 기울기를 비교해 보세요.

eᵢ = yᵢ − ŷᵢ   ·   RSS = Σ(yᵢ − ŷᵢ)² = Σeᵢ² = Σ(yᵢ − axᵢ − b)²
b로 미분   −2Σ(yᵢ − axᵢ − b) = 0

제곱 e² (미분: 2e)

접선 기울기 2.00

바닥(e = 0)에서 기울기가 정확히 0이 됩니다.

절댓값 |e| (미분: ±1)

접선 기울기 1.00

0에서 꺾여 있어 그 점의 기울기를 하나로 정할 수 없습니다. 그래서 공식이 나오지 않고 반복 계산으로 찾습니다.

제곱을 쓰면 미분해서 0이 되는 곳 찾기로 최솟값을 한 번에 구할 수 있습니다.

STEP 3 결과

최적의 직선은 공식으로 한 번에 구할 수 있다

직선을 여러 번 그어 보며 찾지 않아도 공식으로 답을 계산할 수 있습니다.

RSS를 가장 작게 만드는 a와 b

a = Σ(xᵢ−x)(yᵢ−y)  /  Σ(xᵢ−x)²
b = y − ax x, y는 각각 x의 평균과 y의 평균입니다.

이 공식에서 중요한 점

오른쪽에 있는 것은 x와 y뿐입니다.

x와 y는 전부 우리가 이미 가지고 있는 데이터입니다. 찾고 싶은 값 a, b를 데이터만으로 계산할 수 있습니다.

사람은 직선이라는 모양만 정하고, a, b의 값은 데이터로 정했습니다.

어떻게 이 공식이 나왔나

RSS를 a와 b에 대해 각각 미분해서 0으로 놓고 풀면 나옵니다. 미분해서 0이 되는 곳이 최솟값 후보이기 때문입니다.

a, b 공식 유도하기

RSS는 a와 b 두 개의 함수입니다. 하나를 상수로 두고 다른 하나로 미분해서 0으로 놓습니다.

RSS = Σ( yᵢ − axᵢ − b )²
← 가장 작게 만들 식
b로 미분   −2 Σ( yᵢ − axᵢ − b ) = 0
← a는 상수로 보고 b에 대해 미분
Σyᵢ − aΣxᵢ − nb = 0
← 양변을 −2로 나누고, Σ를 항마다 따로 계산 (Σb = nb)
b = y − ax
← 양변을 n으로 나눔 (Σy / n = 평균)
a로 미분   −2 Σ xᵢ( yᵢ − axᵢ − b ) = 0
← b는 상수로 보고 a에 대해 미분
Σ xᵢ( (yᵢ − y) − a(xᵢ − x) ) = 0
← 위에서 구한 b를 대입
Σ xᵢcᵢ = 0
← 긴 괄호 (yᵢ − y) − a(xᵢ − x)를 cᵢ라고 줄여 씀
Σ (xᵢ − x)cᵢ = Σ xᵢcᵢ − x·Σcᵢ = Σ xᵢcᵢ = 0
← 공식을 평균을 뺀 모양으로 맞추려고 xᵢ를 (xᵢ − x)로 바꿔 봄. x는 상수라 Σ 밖으로 나오고, Σcᵢ = 0이라 그 항이 사라져서 값이 같음
Σ (xᵢ − x)( (yᵢ − y) − a(xᵢ − x) ) = 0
← cᵢ를 다시 풀어 씀. xᵢ 대신 (xᵢ − x)를 곱해도 같음
Σ(xᵢ − x)(yᵢ − y) − aΣ(xᵢ − x)² = 0
← 괄호를 풀어 정리
a = Σ(xᵢ − x)(yᵢ − y) / Σ(xᵢ − x)²
← a에 대해 정리

예시: Σcᵢ = Σ( (yᵢ − y) − a(xᵢ − x) ) = 0이 되는 이유

평균에서 뺀 값은 더하면 항상 0입니다. 데이터 x = 1, 2, 3 (x = 2), y = 2, 4, 9 (y = 5), a = 2로 계산해 봅니다.

i = 1i = 2i = 3합
xᵢ − x−10+10
yᵢ − y−3−1+40
(yᵢ − y) − a(xᵢ − x)−3 + 2 = −1−1 − 0 = −14 − 2 = 20

셋째 줄이 위 식의 cᵢ입니다. 합이 0 − a × 0이라 a가 얼마든 0입니다.

STEP 3 행렬로 풀기

최소제곱법을 한 줄로 쓴 식 읽기

"RSS를 가장 작게 만드는 a, b를 찾는다"를 입력이 여러 개인 경우까지 포함해 쓴 것입니다.

ŷ = β₀ + β₁x
β = argminβ Σi (yᵢ − βᵀxᵢ)²

β (베타)

찾고 싶은 계수들을 묶은 것입니다. (β₀, β₁, …, βₚ)로 씁니다.

β (베타 햇)

모자(^)는 데이터로 추정한 값이라는 표시입니다. 진짜 β는 알 수 없고, 우리가 구하는 것은 β입니다.

xᵢ, yᵢ

i번째 데이터의 입력 묶음과 실제값입니다. 광고 예제라면 xᵢ = (1, TVᵢ, 라디오ᵢ, 신문ᵢ)입니다.

βᵀxᵢ: 짝끼리 곱해서 더하기 = 예측값

β₀·1 + β₁·TVᵢ + β₂·라디오ᵢ + β₃·신문ᵢ = ŷᵢ

ᵀ(전치)는 곱셈 모양을 맞추려고 벡터를 눕힌다는 표시입니다.

Σ(yᵢ − βᵀxᵢ)² = RSS

(실제값 − 예측값)을 제곱해서 모든 데이터에 대해 더한 것입니다. 앞에서 본 RSS와 같습니다.

우리말로 읽으면: (실제값 − 예측값)²의 합을 가장 작게 만드는 β를 찾아서 β라고 부릅니다.

STEP 3 행렬로 풀기

βᵀ의 ᵀ: 전치(transpose)

세로로 세워진 벡터를 가로로 눕히는 것입니다. 내용물은 그대로이고 방향만 바뀝니다.

① 벡터는 기본적으로 세로로 씁니다

β = β₀β₁β₂    xᵢ = 1x₁x₂

수학에서는 약속상 벡터를 세로(열벡터)로 씁니다. 여기에 ᵀ를 붙이면 가로(행벡터)가 됩니다.

βᵀ = β₀β₁β₂

② 왜 눕혀야 하나: 행렬 곱셈 규칙

행렬 곱셈은 앞의 가로줄 × 뒤의 세로줄로 계산합니다. 짝끼리 곱해서 더하는 방식입니다. 그래서 곱하려면 앞은 가로, 뒤는 세로여야 합니다.

β₀β₁β₂ 1x₁x₂ = β₀·1 + β₁·x₁ + β₂·x₂ (1×3)(3×1) = 숫자 1개. 이 값이 예측값 ŷᵢ입니다.

세로 β와 세로 xᵢ는 그대로 곱할 수 없습니다. 앞쪽을 눕혀 βᵀxᵢ로 써야 짝끼리 곱해서 더하기가 됩니다.

STEP 3 행렬로 풀기

min이 아니라 argmin인 이유

우리가 알고 싶은 것은 오차가 얼마인지가 아니라 어떤 계수인지입니다.

β = argminβ Σi (yᵢ − βᵀxᵢ)²

min과 argmin

  • min: 최솟값 자체. "가장 작은 RSS는 얼마인가?"
  • argmin: 최솟값을 만드는 입력. "RSS를 가장 작게 만드는 β는 무엇인가?"
f(a) = (a − 3)² + 1
min f = 1,  argmin f = 3 1은 가장 작은 값, 3은 그 값을 만드는 a입니다.

argmin 아래의 β는 "β를 바꿔 가며 찾는다"는 뜻입니다.

STEP 3 행렬로 풀기

행렬식 RSS를 미분해서 정규방정식 얻기

RSS = (Y − Xβ)ᵀ(Y − Xβ) 을 β로 미분해서 0으로 놓습니다. 괄호를 하나씩 미분해 더합니다.

∂RSS/∂β = −Xᵀ(Y − Xβ) − (Y − Xβ)ᵀX 앞 괄호를 미분한 항 + 뒤 괄호를 미분한 항 = −Xᵀ(Y − Xβ) − Xᵀ(Y − Xβ) 두 번째 항은 첫 번째 항을 전치한 것이라 값이 같습니다 (aᵀb = bᵀa) = −2Xᵀ(Y − Xβ) = 0 기울기가 0인 곳이 RSS가 가장 작은 곳

정리하면

XᵀXβ = XᵀY
β = (XᵀX)⁻¹XᵀY

XᵀXβ = XᵀY를 정규방정식(Normal Equation)이라고 하고, 이것을 푼 β가 RSS를 가장 작게 만드는 β입니다.

입력이 하나일 때의 공식과 비교

a = Σ(xᵢ−x)(yᵢ−y)  /  Σ(xᵢ−x)²

x, y에서 각각 평균을 빼 두면 (XᵀX)⁻¹은 분모 Σ(xᵢ−x)²로 나누는 것, XᵀY는 분자 Σ(xᵢ−x)(yᵢ−y)에 해당합니다. 모양은 다르지만 같은 계산입니다.

STEP 3 보충

공식이 없을 때: 경사하강법

선형 회귀는 공식으로 답이 나오지만, 모델의 함수가 복잡해지면 풀 수 있는 공식이 없습니다.

① 식을 풀어서 한 번에

RSS를 가장 작게 만드는 a, b를 공식으로 바로 구합니다.

정확하고 빠르지만, 선형 회귀처럼 간단한 모델에서만 가능합니다.

② 경사하강법 (Gradient Descent)

아무 값에서 시작해, 오차가 줄어드는 방향으로 조금씩 반복해서 이동합니다.

느리지만 함수가 복잡해도 기울기만 구할 수 있으면 쓸 수 있습니다.

한 걸음의 규칙

새 a = 지금 a − η × (지금 위치의 기울기)

기울기가 음수면 a를 키우고, 양수면 줄입니다. η(에타, 학습률)는 한 걸음의 크기입니다. 절편 b도 같은 규칙으로 함께 움직입니다: 새 b = 지금 b − η × (b 방향 기울기).

STEP 3 보충

한 걸음을 식으로 쓰면

절편 없이 ŷ = ax로 두고 a 하나만 움직입니다. 기울기를 계산해 η를 곱한 만큼 옮기는 것이 한 걸음입니다.

a새 = a지금 − η × dMSE/da dMSE/da: a를 조금 늘렸을 때 MSE가 변하는 정도(곡선의 기울기)  ·  η: 학습률

기울기 구하기

MSE(a) = (1/n) Σ (yᵢ − axᵢ)²
dMSE/da = −(2/n) Σ xᵢ(yᵢ − axᵢ)

제곱을 미분한 2(yᵢ − axᵢ)에 괄호 안의 미분 −xᵢ를 곱한 것입니다. 데이터와 지금의 a를 넣으면 숫자 하나가 나옵니다.

왜 기울기를 빼는가

기울기 > 0 → 오른쪽이 오르막이므로 a를 줄입니다.
기울기 < 0 → 오른쪽이 내리막이므로 a를 키웁니다.
기울기 = 0 → 바닥이므로 멈춥니다.

이동량이 기울기에 비례해서, 바닥 근처에서는 저절로 작게 움직입니다.

파라미터가 두 개면

ŷ = ax + b에서는 dMSE/db = −(2/n) Σ (yᵢ − axᵢ − b)도 구해서, 두 기울기를 지금 위치에서 계산한 뒤 a와 b를 동시에 옮깁니다. 이 기울기들을 묶은 것이 그래디언트(gradient)입니다.

학습률 η에 따른 학습 결과

경사하강법에서 사람이 정해야 하는 값입니다. 하이퍼파라미터의 한 예입니다.

너무 작다

η = 0.01

방향은 맞지만 너무 느립니다. 바닥까지 가는 데 걸음이 아주 많이 필요합니다.

적당하다

몇 걸음 만에 바닥에 도착합니다.

너무 크다

η = 0.4

한 걸음이 바닥을 건너뛰어 반대편으로 넘어갑니다. 오차가 점점 커져 발산합니다.

파라미터 vs 하이퍼파라미터

파라미터 — 데이터로 정합니다 (a, b) → 학습의 결과물
하이퍼파라미터 — 사람이 정합니다 (η, 다항식 차수) → 학습의 설정값

하이퍼파라미터를 고르는 방법

여러 값으로 학습해 보고, 테스트가 아닌 별도의 검증 데이터에서 가장 좋은 것을 고릅니다.

STEP 3 보충

손 계산 예제로 보는 학습률

데이터 (1, 2), (2, 4), 시작 a = 0에서 η만 바꿔 봅니다. 기울기는 −5(2 − a)이고 정답은 a = 2입니다.

η남은 거리a의 변화결과
0.010.95배0 → 0.1 → 0.195 → 0.285너무 느림
0.10.5배0 → 1 → 1.5 → 1.75빠르게 도착
0.3−0.5배0 → 3 → 1.5 → 2.25넘나들며 도착
0.4−1배0 → 4 → 0 → 4제자리 왕복
0.5−1.5배0 → 5 → −2.5 → 8.75발산

남은 거리가 몇 배가 되는가

a새 = a − η × (−5)(2 − a)
2 − a새 = (1 − 5η)(2 − a)

한 걸음마다 바닥까지 남은 거리에 (1 − 5η)가 곱해집니다. 음수가 곱해지면 바닥을 건너뛰어 반대편으로 갑니다.

수렴하는 조건

곱해지는 수의 크기가 1보다 작아야 거리가 줄어듭니다.

|1 − 5η| < 1  →  0 < η < 0.4

이 경계값은 데이터마다 다릅니다. 그래서 실제로는 여러 η를 시도해 보고 고릅니다.

STEP 4

예측하고, 얼마나 잘했는지 채점한다

직선을 찾았다면 예측은 대입하면 됩니다. TV에 500만 원을 쓸 때의 매출은 ŷ = a × 500 + b입니다.

아래 RMSE·R²는 학습에 쓰지 않은 테스트 데이터에서 계산해야 실제 성능을 알 수 있습니다.

RMSE

평균적으로 틀린 정도

RMSE = √( RSS / n ) = √MSE

Root Mean Squared Error의 약자로, MSE에 루트를 씌워 원래 단위로 되돌린 값입니다.

매출 단위가 만 원이면 RMSE도 만 원 단위입니다. 평균 3만 원쯤 빗나간다처럼 읽을 수 있어 이해하기 쉽습니다.

R²

설명한 비율

R² = 1 − RSS / TSS TSS = 직선을 안 쓰고 y의 평균으로만 찍었을 때의 오차 제곱합

R² = 1은 완벽하게 맞힌 것, R² = 0은 평균으로 예측한 것과 같습니다. 1에 가까울수록 좋습니다.

테스트 데이터에서는 평균으로 찍는 것보다 못하면 음수가 될 수도 있습니다.

RSS를 그대로 쓰지 않는 이유: RSS는 데이터가 많아지면 저절로 커져서, 개수로 나눈 RMSE나 비율인 R²를 씁니다.

STEP 4 보충

TSS와 R²: 평균으로 찍은 것과 비교하기

x를 보지 않고 모든 데이터를 실제 y값들의 평균 하나로 예측하는 가장 단순한 방법을 기준으로 삼습니다.

TSS: 평균으로 예측했을 때

y = (y₁ + y₂ + ⋯ + yₙ) / n
TSS = Σ (yᵢ − y)²

y는 모델로 구한 값이 아니라 정답 yᵢ를 모두 더해 n으로 나눈 값입니다.

RSS: 직선으로 예측했을 때

ŷᵢ = axᵢ + b
RSS = Σ (yᵢ − ŷᵢ)²

두 식은 yᵢ에서 무엇을 빼느냐만 다릅니다. TSS는 모든 데이터에 같은 y를, RSS는 데이터마다 다른 ŷᵢ를 뺍니다.

예시: 실제 y = 2, 4, 6  →  y = 4

예측 방법y₁ = 2y₂ = 4y₃ = 6제곱합
평균으로 (4, 4, 4)(2 − 4)² = 4(4 − 4)² = 0(6 − 4)² = 4TSS = 8
직선으로 (2.5, 4, 5.5)(2 − 2.5)² = 0.25(4 − 4)² = 0(6 − 5.5)² = 0.25RSS = 0.5

R² = 1 − 0.5 / 8 ≈ 0.94. 평균으로 찍었을 때의 오차 중 94%를 직선이 줄였습니다.

RSS = TSS이면 R² = 0, RSS = 0이면 R² = 1이고, 테스트에서 직선이 평균보다 못하면 RSS > TSS라서 음수입니다.

한 걸음 더

입력이 여러 개면 직선이 평면이 된다

TV·라디오·신문을 한꺼번에 고려하는 것이 다중 회귀입니다.

식이 길어질 뿐입니다

ŷ = b + a₁x₁ + a₂x₂ + a₃x₃ x₁ TV, x₂ 라디오, x₃ 신문

찾을 숫자가 2개에서 4개로 늘었을 뿐 원리는 같습니다. 여전히 RSS를 최소로 만드는 값을 찾습니다.

입력이 1개면 직선, 2개면 평면, 3개 이상이면 그림으로 그릴 수 없는 초평면이 됩니다. 수식은 똑같이 작동합니다.

모델 복잡도 정하기

테스트 오차가 가장 낮은 차수를 고르면 되지 않나요?

앞의 U자 곡선만 보면 그렇게 하고 싶습니다. 하지만 그렇게 하면 테스트 데이터로 공정하게 평가할 수 없게 됩니다.

① 훈련 오차로 고르면

차수를 올릴수록 무조건 내려갑니다.

항상 가장 복잡한 모델(과적합 데모의 차수 12)이 뽑히므로 판단 기준이 될 수 없습니다.

② 테스트 오차로 고르면

시험 문제를 보고 공부법을 고르는 것과 같습니다.

고르는 데 쓴 순간 테스트 데이터는 더 이상 처음 보는 데이터가 아닙니다. 보고하는 점수가 실제보다 좋게 부풀려집니다.

③ 검증 데이터로 고르기

고르는 용도로만 쓰는 데이터를 하나 더 떼어 둡니다.

이것을 검증 데이터(validation)라고 합니다. 차수 같은 하이퍼파라미터는 여기서 정합니다.

고르는 데이터와 채점하는 데이터는 달라야 합니다

테스트 점수를 보고 모델을 고친 뒤 다시 테스트 점수를 보고하면, 그 점수는 내일 들어올 진짜 데이터에서의 성능을 더 이상 말해 주지 않습니다.

풀고 또 풀어도 됩니다. 답을 외워도 괜찮습니다.

검증 데이터 · 모의고사

하이퍼파라미터를 고르는 데 씁니다.

차수 1~12처럼 여러 후보를 여기서 겨루게 한 뒤 가장 잘한 것을 고릅니다. 여러 번 봐도 됩니다.

시험 데이터 · 수능

최종 성능을 보고할 때 딱 한 번 씁니다 (STEP 4).

모델을 고르는 데 절대 쓰면 안 됩니다. 최종 평가 전까지는 보지 않습니다.

시험 데이터를 보고 모델을 고르면 안 됩니다

실제 서비스에서는 이렇게 할 수 없습니다. 추천 시스템의 시험 데이터는 내일 들어올 사용자이고, 내일 일은 오늘 알 수 없습니다. 그런데 연구할 때는 데이터를 미리 떼어 두기 때문에 미리 보고 모델을 고르기 쉽습니다. 이렇게 얻은 점수는 실제 성능보다 높게 나옵니다.

왜 이렇게 하나

데이터를 한 번만 나누면 쉬운 부분이 검증에 들어가 점수가 좋게 나올 수도, 어려운 부분이 걸려 나쁘게 나올 수도 있습니다.

여러 번 돌려 평균을 내면 어떻게 나눴는지에 따른 차이가 줄어듭니다. 모든 데이터가 한 번씩 검증에 쓰여서, 특히 데이터가 적을 때 유용합니다.

자주 나오는 질문

“검증 데이터는 어디서 떼나요?”
시험 데이터를 뺀 나머지에서 떼어 냅니다. 시험 데이터는 여기에 섞이지 않습니다.

실제 진행 순서

학습부터 보고까지, 순서대로

4단계 틀에 모델 고르기 단계가 하나 추가됩니다.

  1. 데이터를 나눈다 — 시험 데이터를 먼저 떼어 따로 보관한다 이후 단계에서는 시험 데이터를 쓰지 않는다.
  2. 훈련 데이터로 학습한다 — STEP 1~3 차수 1짜리, 2짜리, …, 12짜리 후보 모델을 각각 학습시킨다. 파라미터는 여기서 정해진다.
  3. 검증 데이터(또는 교차검증)로 고른다 — 후보 중 가장 좋은 것을 선택 여기서 하이퍼파라미터(차수)가 정해진다. 2~3번을 여러 번 반복해도 된다.
  4. (선택) 다시 학습 — 고른 설정으로 훈련+검증 데이터를 합쳐서 한 번 더 학습 70%보다 85%로 학습하는 편이 조금 더 정확하다.
  5. 시험 데이터로 딱 한 번 성능을 측정해 보고한다 — STEP 4 이 값을 최종 성능으로 보고한다.
실제 진행 순서

검증 오차가 비슷하다면

3단계에서 후보를 비교할 때, 오차만으로 정하지 않고 아래 내용도 함께 봅니다.

함께 보는 것

  • 해석 가능성 — 예측 이유를 설명해야 하는 분야(의료·대출)
  • 단순함 — 성능이 같다면 간단한 모델을 고른다
    “모든 것은 가능한 한 단순해야 하지만, 그보다 더 단순해서는 안 된다.” (아인슈타인이 했다고 알려진 말)
  • 비용 — 학습·추론에 드는 시간과 돈

예

검증 오차설명학습
A0.30쉬움1분
B0.29어려움10시간

대출 심사처럼 이유를 설명해야 한다면 A를 고를 수 있습니다.

오늘 정리

선형 회귀, 한 장으로

ŷ = ax + b  에서  RSS = Σ(y − ŷ)² 를 가장 작게 만드는 a, b 찾기 이 방법을 최소제곱법이라고 합니다.
STEP 1

직선이라 가정

사람은 모양만 정합니다. a, b의 값은 정하지 않습니다.

STEP 2

RSS로 채점

오차를 제곱해서 더합니다. 부호가 없어지고 크게 틀린 점의 벌점이 커집니다.

STEP 3

공식으로 계산

RSS를 최소로 만드는 a, b를 데이터만으로 계산합니다. 공식이 없는 모델은 경사하강법으로 찾습니다.

STEP 4

대입해서 예측

새로운 x를 넣어 ŷ를 얻습니다. 테스트 데이터에서 RMSE·R²로 평가합니다.

꼭 기억할 두 가지

  • 먼저 관계가 있는지 확인합니다. 관계가 없으면 직선도 의미가 없습니다.
  • 관계가 있다고 원인인 것은 아닙니다.
