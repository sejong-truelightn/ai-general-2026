정답 y가 없는 데이터

지도 학습은 입력 x와 정답 y를 짝으로 받아 x에서 y를 맞히는 함수를 배웁니다. 비지도 학습에는 x만 있습니다.

지도 학습
  • 데이터 · (x, y) 짝. x는 데이터, y는 레이블
  • 목표 · x를 y로 보내는 함수 찾기 (함수 근사)
  • 예 · 분류, 회귀
비지도 학습
  • 데이터 · x만 있음. 레이블 없음
  • 목표 · 데이터에 숨어 있는 구조 찾기
  • 예 · 클러스터링, 차원 축소, 밀도 추정

확률과 likelihood: 주머니에서 바둑돌 꺼내기

주머니 A에는 검은 돌 1개와 흰 돌 1개, 주머니 B에는 검은 돌 2개와 흰 돌 1개가 들어 있습니다. 앞 장의 종 모양 후보가 주머니, 키 데이터가 꺼낸 돌에 해당합니다.

●○
주머니 A
●●○
주머니 B
주머니 A주머니 B
검은 돌1/22/3
흰 돌1/21/3

칸마다 들어 있는 값은 모두 같은 조건부 확률입니다. 예: 주머니 B에서 꺼냈을 때 검은 돌일 확률 = 2/3

같은 표를 두 방향으로 읽기

  • 세로로 읽기 = 확률 · 주머니를 하나 정해 놓고 어떤 돌이 나올지 봅니다. A 열은 1/2 + 1/2 = 1이라 확률분포입니다.
  • 가로로 읽기 = likelihood · 나온 돌을 정해 놓고 주머니를 바꿔 가며 봅니다. 검은 돌 행은 1/2 + 2/3 = 7/6이라 합이 1이 아닙니다. 확률분포가 아니라서 likelihood라는 이름을 따로 씁니다.

퀴즈: 돌을 하나 꺼냈더니 검은 돌이었습니다. 어느 주머니에서 꺼냈을까요?

주머니 A라면 검은 돌이 나올 확률은 1/2, 주머니 B라면 2/3입니다. 가로로 읽은 likelihood가 더 큰 B라고 답하는 것이 자연스럽습니다. 이렇게 보이는 결과(돌 색)를 보고, likelihood가 가장 커지는 숨은 원인(주머니)을 고르는 것이 MLE(Maximum Likelihood Estimation, 최대 likelihood 추정)입니다.

likelihood를 식으로 쓰면

데이터 x1, …, xN이 모르는 분포 pθ(x)에서 서로 독립적으로 뽑혔다고 가정합니다. θ는 분포의 성질(모양)을 정하는 숫자입니다.

① 정의: 데이터 전체가 나올 확률

L(θ; x1, …, xN) = pθ(x1, …, xN)

오른쪽은 관측한 데이터가 한꺼번에 나올 확률입니다(결합확률). 데이터는 이미 정해져 있으니 θ만 바뀌는 함수로 보고, 이것을 likelihood라고 부릅니다.

② 서로 독립이면 하나씩 곱하면 된다

L(θ) = pθ(x1) × … × pθ(xN) = ∏i=1..N pθ(xi)

데이터끼리 서로 영향을 주지 않고(독립), 모두 같은 분포 pθ에서 나왔다고 봅니다. 독립이면 함께 일어날 확률은 각각의 확률을 곱한 값입니다.

∏ (파이) = 모두 곱하기

Σ(시그마)가 i = 1부터 N까지 모두 더하기라면, ∏(대문자 파이)는 모두 곱하기입니다.
∏i=1..3 ai = a1 × a2 × a3

동전 예로 계산해 보기

10번 던진 결과는 앞 앞 뒤 앞 앞 뒤 앞 앞 앞 뒤이고, 한 번 던질 때의 확률은 pθ(앞) = θ, pθ(뒤) = 1 − θ입니다.

L(θ) = θ·θ·(1 − θ)·θ·θ·(1 − θ)·θ·θ·θ·(1 − θ) = θ7(1 − θ)3

θ = 0.7을 넣으면 L(0.7) = 0.77 × 0.33 ≈ 0.00222입니다.

여기서는 θ가 앞면 확률이지만, 일반적으로 θ는 분포를 정하는 숫자인 모수(parameter)를 가리킵니다. 정규분포라면 평균 μ가 θ가 됩니다.

log likelihood: 곱을 합으로 바꾸기

likelihood는 확률을 N번 곱한 값이라 다루기 불편해서, 실제로는 log를 씌운 log likelihood를 씁니다(log는 자연로그 ln).

① log를 씌우면 곱이 합이 된다

log L(θ) = log ∏i=1..N pθ(xi)
= Σi=1..N log pθ(xi)

log(a × b) = log a + log b이므로 곱하기가 모두 더하기로 바뀝니다.

밀도 추정

결과가 0 또는 1인 데이터의 MLE

동전처럼 결과가 둘뿐인 데이터에서 가장 그럴듯한 θ를 직접 구해 봅니다. 앞면을 1, 뒷면을 0으로 둡니다.

① 데이터 하나가 나올 확률

pθ(x) = θx(1 − θ)1 − x
  • x ∈ {0, 1} · 데이터 하나의 값
  • θ · 모수, x = 1이 나올 확률

x = 1이면 θ1(1 − θ)0 = θ,
x = 0이면 θ0(1 − θ)1 = 1 − θ입니다. 식 하나로 두 경우를 함께 씁니다.

② likelihood를 가장 크게 만드는 θ

θ̂ = argmaxθ L(θ) = argmaxθ ℓ(θ)
  = argmaxθ Σ log pθ(xi)
  = argmaxθ Σ log θxi(1 − θ)1 − xi
  = argmaxθ  log θ · Σxi + log(1 − θ) · Σ(1 − xi)

ℓ(θ) = log L(θ)는 log likelihood입니다. 마지막 줄은 log ab = b log a를 써서 지수를 앞으로 꺼내고, log θ와 log(1 − θ)끼리 묶은 것입니다.

동전 예 · 앞 7번, 뒤 3번이면 Σxi = 7, Σ(1 − xi) = 3이라서 ℓ(θ) = 7 log θ + 3 log(1 − θ)입니다. 앞 장에서 본 식과 같습니다.

③ 미분해서 가장 큰 θ 찾기 · 가장 큰 곳에서는 기울기가 0입니다.

  1. 미분해서 0으로 두기
    ∂ℓ(θ)/∂θ = (1/θ) Σxi − (1/(1 − θ)) Σ(1 − xi) = 0
    log는 자연로그(ln)라서 (log θ)′ = 1/θ입니다. log(1 − θ)는 연쇄법칙 때문에 부호가 바뀝니다.
    (log(1 − θ))′ = 1/(1 − θ) × (1 − θ)′ = −1/(1 − θ)
  2. 양변에 θ(1 − θ)를 곱하고 괄호 풀기
    (1 − θ) Σxi = θ Σ(1 − xi)
    ⇒ Σxi − θ Σxi = Nθ − θ Σxi
    Σ(1 − xi) = N − Σxi입니다. 양쪽의 θ Σxi가 지워집니다.
  3. θ에 대해 풀기
    Σxi = Nθ  ⇒  θ̂ = (1/N) Σxi

θ̂ = 1이 나온 횟수 ÷ 전체 횟수, 즉 데이터의 평균입니다. 동전 예라면 7 / 10 = 0.7로, likelihood 곡선의 봉우리와 같습니다.
해석 · 앞 7번, 뒤 3번이라는 결과가 나올 확률은 θ = 0.7일 때 약 0.00222로, θ가 다른 어떤 값일 때보다 큽니다. 그래서 θ를 0.7로 추정합니다. θ가 0.7일 확률이 가장 높다는 뜻은 아닙니다.

정규분포의 MLE

키 5명(164, 168, 170, 172, 176cm)이 정규분포에서 나왔다고 보고, 이 정규분포의 모양을 정하는 θ를 데이터로 구합니다.

pθ(x) = 1σ√(2π)e−12(x − μσ)²

정규분포 식입니다. 모수가 θ = {μ, σ} 두 개입니다. μ는 평균(종 모양의 가운데), σ는 표준편차(퍼진 정도)이고 σ²가 분산입니다.

MLE: likelihood를 가장 크게 만드는 θ

θ̂ = argmaxθ L(θ; x1, …, xN) = argmaxθ ℓ(θ; x1, …, xN)
  = argmaxθ Σ log pθ(xi) = argmaxθ Σ log 1σ√(2π)e−12(xi − μσ)²

ℓ(θ) = log L(θ)는 log likelihood입니다. 데이터가 서로 독립이라 L은 pθ(xi)를 N번 곱한 값이고, log를 씌우면 곱이 합이 됩니다. log는 값이 커질수록 같이 커지므로 L과 ℓ이 가장 큰 θ는 같습니다.

밀도 추정

정규분포의 MLE (이어서)

ℓ(θ)를 log(a × b) = log a + log b, log ez = z로 두 덩어리로 나누고, μ와 σ로 각각 미분해서 0이 되는 값을 구합니다.

ℓ(θ) = Σ log 1σ√(2π)e−12(xi − μσ)²
  = Σ log 1σ√(2π) − Σ 12(xi − μσ)²

① μ로 미분

∂ℓ(θ)∂μ = Σ xi − μσ² = 0
→ Σ xi = Σ μ = Nμ  →  μ̂ = 1NΣ xi

첫째 덩어리는 μ가 없어서 0, 둘째 덩어리는 연쇄법칙으로 ((xi − μ)²)′ = −2(xi − μ)입니다.
키 데이터: μ̂ = 850 / 5 = 170, 키의 평균입니다.

② σ로 미분

∂ℓ(θ)∂σ = −Nσ − 12 · (−2)σ−3 Σ (xi − μ)² = 0
→ Nσ = 1σ³Σ (xi − μ)²  →  σ̂² = 1NΣ (xi − μ̂)²

log(1 / σ√(2π)) = −log σ − log √(2π)라서 첫째 덩어리를 미분하면 −1/σ이 N번 더해지고, 둘째 덩어리는 σ−2을 미분해 −2σ−3이 됩니다.
키 데이터: σ̂² = (36 + 4 + 0 + 4 + 36) / 5 = 16, 키의 분산입니다.

σ를 5로 두고 계산하면 likelihood는 μ = 170일 때가 160, 180일 때보다 약 2만 배 큽니다. 그림을 보고 가운데 종 모양을 고른 것이 숫자로도 맞습니다.

MLE로 다시 보기

최소제곱법을 likelihood로 다시 보기

직선 모델 y = ax + b + ε에서 오차 ε가 평균 0, 분산 σ²인 정규분포를 따른다고 가정하고, 정규분포의 MLE와 같은 순서로 풉니다.

θ̂ = argmaxθ L(θ; (x1, y1), …, (xN, yN))
  = argmaxθ ℓ(θ; (x1, y1), …, (xN, yN)) = argmaxθ Σ log pθ(yi | xi)
  • 여기서 θ는? · 직선을 정하는 두 숫자 θ = {a, b}입니다.
  • pθ는? · 정규분포 식에서 두 곳을 바꿉니다. 맞히려는 값이 이제 y이고, 종 모양의 가운데(평균)가 직선 ax + b입니다.
pθ(x) = 1σ√(2π)e−12(x − μσ)²
→ pθ(y | x) = 1σ√(2π)e−12(y − (ax + b)σ)²

pθ(y | x)는 x가 주어졌을 때 y가 나올 확률입니다(오른쪽 그림).

MLE로 다시 보기

최소제곱법을 likelihood로 다시 보기 (이어서)

MLE는 log likelihood를 가장 크게 만드는 θ, 여기서는 a, b를 찾는 일입니다.

ℓ(θ) = Σ log pθ(yi | xi) = Σ log 1σ√(2π)e−12(yi − (axi + b)σ)²
  = Σ log 1σ√(2π) − Σ 12(yi − (axi + b)σ)²
argmaxθ ℓ(θ) = argmaxa, b Σ log 1σ√(2π) − Σ 12(yi − (axi + b)σ)²  파란 상자는 a, b와 상관없음 → 지웁니다
  = argmaxa, b −Σ (yi − (axi + b))² = argmina, b Σ (yi − (axi + b))²  최소제곱법!

log(a × b) = log a + log b로 두 덩어리로 나눴습니다. 첫째 덩어리는 a, b가 바뀌어도 그대로인 숫자라서 빼도 되고, ½과 σ는 양수라서 나누거나 곱해도 가장 큰 곳의 a, b가 바뀌지 않습니다. 마이너스를 붙인 값이 가장 크다는 것은 붙이기 전 값이 가장 작다는 뜻이라 argmax가 argmin으로 바뀝니다. 마지막 식의 Σ(yi − ŷi)²가 RSS입니다.

결론 · 다시 말해 선형 회귀에서 MLE는 최소제곱법입니다. 오차가 정규분포를 따르고 그 분산 σ²가 모든 데이터에서 같다고 가정하면, likelihood를 가장 크게 만드는 a, b와 RSS를 가장 작게 만드는 a, b가 같습니다.

묶기 전에 정할 것

두 데이터가 얼마나 다른지 숫자로 재기

직접 계산하기

L1(A, B) = Σj | Aj − Bj |차이의 절댓값을 모두 더함
L2(A, B) = √ Σj ( Aj − Bj )²차이를 제곱해 더하고 제곱근 (직선거리)

  2. 그룹 하나를 골라 멀리 떨어진 두 덩어리로 나눕니다. 나눌 때는 뒤에서 볼 K-평균을 K = 2로 쓰는 경우가 많습니다.
  3. 원하는 그룹 수가 될 때까지 2를 반복합니다.

상향식은 가까운 점끼리 합치는 작은 판단을 쌓아 올리고, 하향식은 큰 덩어리부터 나눕니다. 어느 쪽이든 과정을 나무 모양으로 그릴 수 있습니다. 위 그림은 오른쪽 나무 그림을 위에서부터 읽은 순서입니다.

가장 가까운 쌍은 두 덩어리 사이에 징검다리처럼 늘어선 점들이 있으면 전체를 하나로 이어 버립니다. 가장 먼 쌍은 크고 둥근 덩어리를 억지로 쪼갭니다. 평균을 쓰면 중심 근처는 잘 반영되지만 가장자리 점들의 모양은 잘 드러나지 않습니다. 어느 방법이 맞는지는 데이터마다 다르므로 직접 해 보고 결과를 보며 고릅니다.

묶는 방법 ② · 가장 널리 쓰는 방법

K-평균 (K-means)

이름 그대로 K개의 평균을 찾습니다. 단순하지만 지금도 가장 많이 쓰는 클러스터링 방법입니다.

알고리즘

  1. 그룹 개수 K를 정한다K는 사람이 미리 정해 줘야 합니다.
  2. K개의 점을 아무 데나 놓는다이 점들을 각 그룹의 중심, 센트로이드(centroid)라고 부릅니다.
  3. 배정 단계 · 모든 데이터를 가장 가까운 센트로이드의 그룹에 넣는다
  4. 이동 단계 · 각 센트로이드를 자기 그룹에 속한 데이터의 평균 위치로 옮긴다
  5. 배정이 더 이상 바뀌지 않을 때까지 3, 4를 반복한다

두 단계가 하는 일

배정 단계는 센트로이드를 고정하고 데이터의 소속을 바꿉니다. 센트로이드가 두 개라면 두 점을 이은 선분의 수직이등분선이 경계가 됩니다.

이동 단계는 소속을 고정하고 센트로이드를 옮깁니다. 그룹에 속한 점들의 좌표를 모두 더해 개수로 나누면 새 위치가 나옵니다.

식으로 쓰기

K-평균이 줄이려는 값 J

J는 각 점이 자기 그룹 센트로이드에서 얼마나 떨어져 있는지를 모두 더한 값입니다. J가 작을수록 그룹이 촘촘하게 잘 뭉쳐 있습니다.

J = Σi=1..N Σk=1..K rik ‖xi − μk‖² xi는 i번째 데이터(N개), μk는 k번째 그룹의 센트로이드(K개), rik는 xi가 그룹 k에 속하면 1, 아니면 0입니다.
Σ 두 개로 모든 점과 모든 센트로이드의 짝을 훑지만, rik = 0인 항은 사라지므로 자기 그룹 센트로이드까지의 거리 제곱만 더해집니다.

J에서 정해야 할 것은 소속 rik와 센트로이드 μk 두 가지입니다. 둘을 한 번에 정하기는 어려워서, 하나를 고정하고 다른 하나를 정하는 일을 번갈아 반복합니다.

① 배정 · 센트로이드는 그대로, 소속을 정한다

rik = 1  (k = argminj ‖xi − μj‖²일 때)

점 xi에서 모든 센트로이드까지 거리를 재고, 가장 가까운 센트로이드의 번호 k에만 1을 줍니다. 센트로이드가 정해져 있을 때 J를 가장 작게 만드는 방법은 각 점을 가장 가까운 센트로이드에 넣는 것입니다.

② 이동 · 소속은 그대로, 센트로이드를 정한다

μk = Σi rikxi ÷ Σi rik

분자는 그룹 k에 속한 점들의 좌표 합, 분모는 그 점의 개수이므로 μk는 그룹의 평균입니다. 그룹이 정해져 있을 때 거리 제곱의 합을 가장 작게 만드는 위치가 평균입니다. J를 μk로 미분해서 0으로 놓으면 이 식이 나오고, 정규분포의 MLE에서 μ̂가 평균으로 나온 것과 같은 원리입니다.

알고리즘이라면 갖춰야 할 성질

K-평균은 반드시 멈추는가

알고리즘은 어떤 입력이 들어와도 원하는 결과를 내고, 반드시 끝나야 합니다. K-평균의 종료 조건은 “배정이 바뀌지 않을 때까지”입니다. 계속 바뀌는 일은 생기지 않을까요?

문제가 될 수 있는 경우

어떤 점이 두 센트로이드와 정확히 같은 거리에 있으면, 한 번은 이쪽, 한 번은 저쪽으로 오가며 끝나지 않을 수 있습니다.

해결 · 거리가 같으면 옮기지 않습니다. 더 가까워질 때만 소속을 바꾸도록 정합니다.

J는 늘지 않는다

배정 단계에서는 더 가까운 센트로이드로만 옮기므로 J가 줄거나 그대로입니다.

이동 단계에서는 그룹 안 거리 제곱의 합을 가장 작게 만드는 위치가 평균이므로, 역시 J가 줄거나 그대로입니다.

경우의 수가 유한하다

N개의 점을 K개의 그룹에 나누는 방법은 많아야 KN가지입니다. 배정이 바뀔 때마다 J가 줄어들므로, J가 더 컸던 예전 배정으로 되돌아가는 일은 없습니다.

경우의 수가 유한하므로 언젠가는 더 줄일 수 없는 상태에 도착하고 멈춥니다.

경사하강법처럼 값을 조금씩 미분해 움직이는 방식이었다면 이런 논리를 쓸 수 없습니다. K-평균은 배정을 통째로 바꾸는 방식이고, 가능한 배정이 유한하기 때문에 종료가 보장됩니다.

한계 ①

시작점에 따라 결과가 달라진다

과정은 모두 정해진 계산이라서 같은 시작점이면 같은 결과가 나옵니다. 시작점이 다르면 전혀 다른 결과가 나올 수 있습니다.

잘못된 결과의 모양

K = 4로 같은데, 가까이 붙은 두 덩어리를 하나로 묶고 다른 한 덩어리를 둘로 쪼개는 결과가 나오기도 합니다. 거기서는 어느 점을 옮겨도 J가 줄지 않아서 그대로 멈춥니다.

그래서 실제로는

시작점을 바꿔 가며 여러 번 돌리고, 그중 J가 가장 작은 결과를 고릅니다. 알고리즘이 스스로 해 주지 않으므로 사용하는 사람이 챙겨야 합니다.

한계 ②

얼마나 오래 걸릴까

데이터 N개, 그룹 K개일 때 한 번 반복하는 데 드는 계산량을 세어 봅니다.

부분계산량이유
배정 단계O(KN)점 N개마다 센트로이드 K개와의 거리를 모두 계산해서 가장 작은 것을 고릅니다.
이동 단계O(N)그룹마다 평균을 내지만, 점 하나는 딱 한 그룹에만 들어가므로 전체로 보면 점마다 한 번씩만 더합니다.
반복 횟수 (최악)KN가능한 배정을 하나씩 다 거쳐 가는 최악의 경우입니다. N이 조금만 커져도 엄청난 수입니다.

실제로는

최악의 경우는 거의 일어나지 않고, 대부분 몇 번에서 수십 번 반복하면 멈춥니다. 앞의 데모에서도 몇 번 만에 끝났습니다. 그래서 큰 데이터에도 부담 없이 씁니다.

빨리 끝나는 이유

J가 더 이상 줄지 않는 지점(국소 최솟값)에 금방 도착하기 때문입니다. 빨리 끝나는 대신 그 지점이 가장 좋은 답이라는 보장은 없습니다. 앞 장에서 본 한계와 같은 이야기입니다.

K는 몇으로 할까

엘보 방법 (elbow method)

데이터의 성격상 그룹 수를 미리 아는 경우가 아니라면 K를 여러 값으로 바꿔 가며 비교해야 합니다.

J가 가장 작은 K를 고르면 안 됩니다

센트로이드를 하나 더 놓으면 어떤 점은 그쪽이 더 가까워지고, 멀어지는 점은 없습니다. 그래서 K가 커질수록 J는 무조건 줄어듭니다. 점 개수만큼 K를 늘리면 J는 0이 됩니다. 그래서 교차 검증으로 J를 비교해 K를 고르는 방식은 여기서 통하지 않습니다.

꺾이는 지점을 봅니다

J가 크게 줄다가 어느 순간부터 조금씩만 줄어드는 지점이 팔꿈치처럼 생겨서 엘보라고 부릅니다. 그 뒤로는 억지로 쪼개는 것에 가깝습니다. 실제 데이터에서는 꺾이는 곳이 뚜렷하지 않을 때도 많습니다.

훈련 오차

학습 내내 꾸준히 내려갑니다. 매번 훈련 데이터 일부만 보고 고쳐서 조금씩 오르내립니다.

검증 오차

훨씬 크게 흔들립니다. 100번 근처까지 내려가다가 그 뒤로는 다시 올라갑니다.

정해야 할 것

검증 오차가 이렇게 흔들리면, 어느 시점의 값을 이 모델의 성능으로 볼지와 언제 학습을 멈출지를 정해야 합니다. 훈련 오차는 계속 내려가는데 검증 오차가 다시 올라가는 이 현상을 과적합이라고 합니다.

개념

과적합(Overfitting)

모델이 훈련 데이터의 일반적인 패턴뿐 아니라 그 데이터에만 우연히 들어 있는 잡음까지 맞추는 현상입니다.

훈련 오차는 계속 내려가는데 검증 오차가 다시 올라가기 시작하면 과적합입니다.

잡음이 생기는 예

아파트 단지 길고양이 사진만 모으면, 모델은 그 품종의 털 색과 무늬까지 고양이의 특징으로 배웁니다. 그러면 페르시아 고양이 사진을 보고 고양이가 아니라고 답할 수 있습니다.

학습하면서 배우는 순서

  1. 큰 패턴을 먼저 배웁니다. 네 다리, 얼굴 생김새, 수염처럼 어느 고양이 사진에나 있는 특징입니다. 훈련·검증 오차가 함께 내려갑니다.
  2. 세부 패턴을 배웁니다. 발톱 모양, 귀털처럼 작은 특징입니다. 훈련 오차는 계속 내려가지만 검증 오차는 거의 그대로입니다.
  3. 잡음을 배웁니다. 훈련 데이터에만 우연히 있던 특징을 규칙으로 외웁니다. 검증 오차가 올라갑니다.
왜 생길까

훈련 오차와 검증 오차가 갈라지는 이유

두 데이터는 같은 분포에서 뽑았지만, 우연히 섞여 들어간 잡음은 서로 다릅니다.

훈련 오차는 계속 내려갑니다

학습은 훈련 데이터에서 틀린 만큼을 계산해서 덜 틀리는 방향으로 파라미터를 고치는 일입니다. 훈련 데이터 전체를 보고 고치면 한 번 고칠 때마다 훈련 오차가 줄어듭니다. 곡선이 들쭉날쭉한 것은 데이터 일부만 보고 고쳤기 때문입니다.

검증 오차는 보장이 없습니다

검증 데이터는 학습에 쓰지 않았습니다. 모델이 배운 패턴이 검증 데이터에도 있으면 검증 오차가 내려가고, 훈련 데이터에만 있던 패턴이면 검증 데이터에서는 오히려 틀리게 됩니다.

정리

과적합을 막으려면 정해야 할 두 가지

사람은 모델의 모양을 정하고, 계수는 데이터에서 찾습니다. 어느 정도가 알맞은지는 학습해 보기 전에는 알기 어렵습니다.

1

언제 멈출까

오래 학습하면 큰 패턴을 다 배운 뒤 잡음까지 외웁니다. 학습을 너무 일찍 멈추면 과소적합, 너무 늦게 멈추면 과적합이 됩니다.

조절하는 값: 학습 반복 횟수

2

모델을 얼마나 크게 만들까

모델이 너무 작으면 큰 패턴도 배우지 못하고, 너무 크면 잡음까지 외울 여유가 생깁니다. 모델의 크기는 배워야 하는 파라미터의 개수로 봅니다. 가장 작은 모델은 평균값 하나만 기억하는 상수 모델입니다.

조절하는 값: 다항식 차수, 변수 개수

목표

과소적합도 과적합도 아닌, 훈련 데이터의 일반적인 패턴을 배운 지점에서 학습을 끝내는 것입니다. 다음 장에서 학습 반복 횟수와 다항식 차수를 직접 바꿔 봅니다.

언제 멈출까

조기 종료(Early Stopping)

학습하는 동안 검증 오차를 기록하다가, 가장 낮은 지점에서 멈춥니다.

검증 곡선은 들쭉날쭉해서, 여러 번 연속으로 나아지지 않을 때 멈추고 가장 좋았던 시점의 파라미터를 씁니다.

시험 곡선 대신 검증 곡선을 보는 이유

세 데이터는 같은 분포에서 뽑았지만 잡음은 서로 다릅니다. 검증 오차가 오르기 시작하면 훈련 데이터에만 있던 잡음을 배우기 시작한 것이고, 시험 데이터에서도 비슷한 시점에 같은 일이 일어납니다.

곡선의 높이는 보지 않습니다

어느 곡선이 더 높은지는 뽑힌 데이터가 쉬웠는지에 달렸습니다. 보는 것은 내려가다 다시 올라가는 시점입니다.

무엇으로 재나요? 실제로 관심 있는 지표로 잽니다

학습은 미분할 수 있는 손실로 하지만, 멈출 시점은 정확도처럼 실제로 원하는 지표로 정하는 편이 좋습니다. 손실은 아직 내려가는데 정확도는 이미 나빠지는 경우가 있기 때문입니다.
