PART 1 · 지도 그리기

인공지능이란 무엇인가

人工  人 사람 인 · 工 만들 공  →  사람이 만들어 낸 지능

인간이나 동물의 지능이 아닌, 기계와 소프트웨어가 갖는 지능

그렇다면 여기서 말하는 지능이란?

단순히 계산을 잘하는 것을 넘어, 외부 정보를 인식하고 이해하며, 이를 활용해 적응적인 행동을 결정하는 고차원적 사고 능력.

인공지능을 구현하는 데에는 두 가지 철학이 존재합니다.

철학 ①

뇌를 모사한다

인간의 뇌와 지능이 작동하는 원리 자체를 흉내 내려는 방식.

철학 ②

기계에 맞는 방법을 찾는다

사람과 같을 필요는 없다. 기계에 적합한 통계적·수학적 방식으로 효율을 추구하는 방식.

HISTORY

두 철학의 우위는 두 번 뒤집혔다

지금은 당연해 보이는 신경망이, 한때는 실패한 접근으로 여겨졌습니다.

1956

출발

다트머스 회의에서 ‘인공지능’이라는 말이 처음 등장. 두 철학이 나란히 출발.

1957

① 등장

로젠블랫의 퍼셉트론 — 스스로 가중치를 조정하는 최초의 신경망.

기대가 과열됨 (“스스로 걷고 말하게 될 것” — NYT, 1958)

1969

① 몰락

민스키·페퍼트가 단층 퍼셉트론은 XOR도 못 푼다고 증명. 연구비가 끊기고 규칙·탐색 기반이 주류로.

이 시대의 정점이 1997년 딥블루

1986

불씨

역전파(backpropagation) 알고리즘이 널리 퍼지며 여러 층을 쌓은 신경망을 훈련할 길이 열림.

2012

① 부활

AlexNet이 ImageNet 대회에서 오차율을 26% → 15%로 끌어내리며 압승. 딥러닝 시대 개막.

그래서 어느 철학이 이겼나?

어느 한쪽의 승리가 아닙니다. 구조는 철학①에서 빌려오고, 그 구조를 훈련시킨 방법은 철학②입니다.
신경망이라는 이름은 뇌에서 왔지만, 실제로 학습을 굴리는 건 경사하강법·확률·선형대수입니다. (실제 뇌는 역전파를 쓰지 않습니다.)

2012 · 결정적 장면

ImageNet 오차율의 붕괴

120만 장의 사진을 1000개 범주로 분류하는 대회. 세로축은 틀린 비율이라 낮을수록 좋습니다.

2012 — AlexNet

0.26 → 0.16. 한 해에 10%p가 무너졌습니다. 이전까지는 매년 1~2%p씩 줄던 대회였습니다.

사람은 몇 %일까?

훈련받은 사람의 오차율은 약 5.1%로 측정됐습니다.
→ 2015년(3.6%)에 기계가 사람을 넘어섭니다.

PART 1 · 지도 그리기

AI · 머신러닝 · 딥러닝은 무슨 관계?

인공지능 (AI)사람처럼 판단·행동하는 모든 기법
머신러닝 (ML)데이터로 규칙을 스스로 찾음
딥러닝인공신경망

AI

기계와 소프트웨어가 갖는 지능 전부. 사람이 규칙을 다 짜 넣어도 AI다.

AI지만 ML은 아닌 것
· 탐색 알고리즘 — 내비게이션 최단 경로, 체스의 미니맥스
· 규칙 기반 시스템 — “열 38도 이상 + 기침 → 독감 의심”을 사람이 직접 입력

ML

규칙을 사람이 안 짜고 데이터에서 뽑아낸다. AI의 부분집합.

DL

ML 중에서도 깊은 신경망을 쓰는 방법. 나중에 Deep Q-Learning으로 연결.

딥블루 vs 알파고 — 둘 다 AI, 하나만 ML

딥블루 (1997, 카스파로프에게 승리)
사람이 짜 넣은 평가 함수로 초당 2억 수를 탐색. 한 판도 스스로 배우지 않음 → ML 아님

알파고 (2016, 이세돌에게 승리)
기보와 자기 대국 데이터로 스스로 규칙을 학습 → ML (딥러닝 + 강화학습)

세 갈래를 가르는 기준은 학습에 무엇이 주어지는가입니다 — 정답표 / 입력만 / 보상.

지도학습 · SUPERVISED

정답(label)을 보고 배운다

입력 x 와 정답 y 쌍을 잔뜩 주고, y ≈ f(x) 인 함수 f를 찾게 한다.

분류 (Classification)

출력이 정해진 몇 개의 범주 중 하나

  • 이 메일은 스팸인가 / 아닌가
  • 이 사진은 개 / 고양이 / 새
  • 이 세포 이미지는 정상 / 이상

출력: 이산적(discrete)

회귀 (Regression)

출력이 연속적인 숫자

  • 이 아파트의 가격은 얼마?
  • 내일 최고기온은 몇 도?
  • 이 학생의 다음 시험 점수는?

출력: 연속적(continuous)

실제 데이터는 이렇게 생겼습니다 — 정답 열(y)이 이미 채워져 있다는 게 핵심.

입력 x (특성) 정답 y — 분류정답 y — 회귀
공부 시간결석 일수이전 성적 합격 여부다음 시험 점수
12시간0일82점합격88점
3시간5일51점불합격47점
8시간2일68점 ? ← 예측할 값? ← 예측할 값

마지막 줄이 새 학생입니다 — 입력은 알고, 정답만 모릅니다. 그 빈칸을 채우는 게 예측이고요.
입력이 같아도 무엇을 정답 열로 두느냐에 따라 분류 문제가 되기도, 회귀 문제가 되기도 합니다.

한 줄 요약: 누군가 정답을 미리 다 채점해 놓아야 학습이 시작된다. ← 데이터 라벨링 비용이 큰 이유

비지도학습 · UNSUPERVISED

정답 없이 구조를 찾는다

입력 x 만 주고, 데이터 안에 숨은 패턴·구조를 스스로 드러내게 한다.

군집화

Clustering

비슷한 것끼리 묶기

  • 고객을 구매 패턴별 그룹으로
  • 뉴스 기사 자동 주제 묶음

k-means, DBSCAN

변환

Transformation

데이터를 더 다루기 쉬운 형태로

  • 100개 특성 → 2개로 줄여 시각화
  • 노이즈 제거·압축

PCA, t-SNE, 오토인코더

연관

Association

함께 나타나는 규칙 찾기

  • “기저귀를 사면 맥주도 산다”
  • 장바구니 분석, 추천

Apriori, FP-Growth

같은 데이터라도 정답 열이 없습니다. 대신 “이 학생들은 몇 개의 유형으로 나뉘나?”를 묻습니다.

공부 시간결석 일수이전 성적→ 정답 열 없음
12시간0일82점군집 A (성실형)
3시간5일51점군집 B (이탈 위험형)

군집 이름 “성실형/이탈 위험형”은 AI가 붙인 게 아니라 사람이 나중에 해석해서 붙인 것입니다.

한 줄 요약: 답을 맞히는 게 아니라, 데이터의 지도(map)를 그리는 일.

강화학습 · REINFORCEMENT

행동하고, 점수를 받으며 배운다

정답표도 없고, 미리 모아둔 데이터도 없다. 직접 해 보고 돌아오는 점수(보상)만으로 배운다.

주어지는 것

  • 내가 놓인 상황(상태)
  • 고를 수 있는 행동 목록
  • 행동 뒤 돌아오는 점수(보상)

“무엇을 해야 하는지”는 아무도 안 알려줌

어려운 이유

  • 보상이 늦게 온다 — 바둑은 300수 뒤에야 승패를 앎
  • 그래서 어느 행동이 잘한 것인지 골라내기 어렵다 (신용 할당 문제)

고유한 딜레마

탐험 vs 활용

새로운 걸 시도해 볼까(탐험), 지금까지 제일 좋았던 걸 또 할까(활용)?

지도·비지도학습에는 없는 고민

비유: 자전거를 배우는 과정

아무도 “핸들을 3.7도 왼쪽으로 꺾어라”라고 정답을 주지 않습니다. 넘어지면 아프고(−), 안 넘어지고 나아가면 기분이 좋습니다(+). 그 점수만으로 몸이 규칙을 찾아냅니다.

한 줄 요약: 무엇을 해야 하는지는 안 알려주고, 얼마나 잘했는지만 알려준다.

PART 2 · 강화학습

이 수업이 향하는 곳

세 갈래 중 우리가 파고들 곳은 강화학습입니다.

“누가 정답을 채점해 주지 않아도, 스스로 시행착오를 겪으며 배우는 AI를 직접 만든다”

주의 — 강화학습도 데이터를 씁니다. 다만 미리 라벨링된 데이터셋을 받는 게 아니라, 직접 행동해서 그 데이터를 만들어 냅니다.

① 원리를 이해한다

공식과 그림으로 알고리즘이 왜 작동하는지 파악

② 밑바닥부터 구현한다

라이브러리 호출이 아니라 갱신식을 직접 코딩

③ 내 문제에 적용한다

스스로 시나리오를 설계해 문제를 정의

핵심 습관: “이 문제를 상태·행동·보상으로 바꾸면 뭐가 되지?” — 수업 내내 반복할 질문입니다.

강화학습

강화학습이란 무엇인가

에이전트가 환경과 상호작용하며,
받은 보상의 총합을 최대로 만드는 행동 규칙을 스스로 찾아가는 학습

에이전트
Agent
──── 행동 aₜ ────▶
◀── 상태 sₜ₊₁, 보상 rₜ₊₁ ──
환경
Environment

이 한 바퀴가 강화학습의 전부입니다. 앞으로 배울 모든 알고리즘은 이 루프를 어떻게 도느냐의 차이일 뿐.

PART 3

강화학습을 세우는 5가지 원칙

새로운 문제를 만났을 때 이 순서대로 정의하면, 어떤 문제든 강화학습 문제로 바꿀 수 있습니다.

1

입력과 출력 시스템

AI는 무엇을 보고(입력), 무엇을 하는가(출력)

2

보상

잘한 행동과 못한 행동을 숫자로 어떻게 알려줄까

3

AI 환경

상태·행동·보상을 한 덩어리로 묶은 세계

4

마르코프 결정 프로세스 (MDP)

그 세계를 푸는 수학적 뼈대

5

훈련과 추론

배우는 단계와, 배운 걸 써먹는 단계를 구분한다

1
PRINCIPLE 01

입력과 출력 시스템

AI는 결국 입력을 받아 출력을 내놓는 함수입니다. 무엇을 넣고 무엇을 뺄지부터 정해야 합니다.

입력 = 상태 (State)

AI가 지금 관찰할 수 있는 것 전부. 관찰 못 하는 건 넣으면 안 됨.

출력 = 행동 (Action)

AI가 실제로 고를 수 있는 선택지 목록.

정책 (Policy) π

모든 상태에 대해 어떤 행동을 할지 적어둔 지침서 전체. 학습이란 곧 이 π를 고쳐 나가는 일.

예: 미로를 탈출하는 로봇

입력(상태) = 현재 칸 번호 (0~11)  ·  출력(행동) = 상/하/좌/우 4가지

정책 π = 12개 칸 전부에 대한 지침 한 벌  { 0→우, 1→하, 2→우, …, 5→우, … }

흔한 실수 — 상태에 “정답으로 가는 방향”을 몰래 넣기. 그건 이미 답을 알려준 것이라 학습이 아닙니다.

2
PRINCIPLE 02

보상 (Reward)

보상은 “무엇을 잘하라”는 유일한 지시문입니다. 방법은 안 알려주고 목표만 알려줍니다.

좋은 보상 설계

  • 도착: +1, 그 외 매 걸음: −0.04 → 빨리 도착하게 유도
  • 목표와 직결된 값만 준다
  • 스케일을 일정하게 유지

망가지는 보상 설계

  • 보상이 도착할 때만 발생 → 신호가 너무 희박(sparse)
  • 의도치 않은 지름길이 존재 → 보상 해킹
    청소 로봇에 “먼지 흡입량 +1” → 먼지를 다시 뿌리고 또 빨아들임
3
PRINCIPLE 03

AI 환경 (Environment)

환경 = 상태 + 행동 + 보상을 하나로 묶은, AI가 살아가는 세계 그 자체.

환경이 하는 일 (코드로 보면)

state = env.reset()          # 세계를 초기화
while not done:
    action = agent.act(state)          # 원칙 1
    state, reward, done = env.step(action)  # 원칙 2·3
    agent.learn(...)                   # 원칙 5

구현 실습에서 env는 미리 제공되고, 여러분은 agent 쪽을 채웁니다.

환경을 정의한다는 것

  • 가능한 상태 전부 나열하기
  • 각 상태에서 가능한 행동 나열하기
  • 행동하면 어느 상태로 가는지 규칙 정하기
  • 언제 에피소드가 끝나는지(done) 정하기

현실 문제를 환경으로 바꾸는 것 = 응용 실습의 핵심 과제

PRINCIPLE 04

마르코프 결정 프로세스 (MDP)

마르코프 결정 프로세스는 시간이 지남에 따라 AI가 환경과 어떻게 상호작용하는지를 모델링하는 프로세스다.

이 프로세스는 t = 0 에서 시작해 t = 1, t = 2, …, t = n 으로 반복된다. 시간 단위는 어떤 것이든 올 수 있다 (예를 들어 1초도 가능하다). 반복할 때마다 AI는 동일한 형태의 전이(transition) 과정을 따른다.

1

상태를 관측한다

AI는 현재 상태 st 를 관측한다.

2

행동을 수행한다

AI는 행동 at 를 수행한다.

3

보상을 받는다

AI는 보상 rt = R(st, at) 를 받는다.

4

다음 상태로 간다

AI는 다음 상태 st+1 에 들어간다.

AI의 목적은 항상 같다

시간에 따라 누적된 보상, 즉 전이마다 받는 rt = R(st, at) 의 전체 합을 극대화하는 것.

PRINCIPLE 04 · 심화

MDP를 이루는 5개 부품 ⟨S, A, P, R, γ⟩

기호이름뜻미로 로봇 예시
S상태 집합
State		 AI가 처할 수 있는 모든 상황의 집합미로의 12개 칸 {0,1,…,11}
A행동 집합
Action		 각 상태에서 고를 수 있는 선택지{상, 하, 좌, 우}
P전이 확률
Transition		 s에서 a를 했을 때 s′로 갈 확률
P(s′|s,a)		 “오른쪽”을 누르면 90% 오른쪽, 10% 미끄러짐
R보상 함수
Reward		 상태·행동에 대해 돌아오는 점수도착 +1, 함정 −1, 일반 칸 −0.04
γ감가율
Discount		 미래 보상을 얼마나 중요하게 볼지 (0~1)γ = 0.9

PRINCIPLE 05

훈련(Training)과 추론(Inference)

훈련 모드

  • 일부러 새로운 행동을 시도한다 (탐험 · exploration)
  • 보상을 받을 때마다 정책/Q값을 갱신
  • 당장 손해를 봐도 괜찮다 — 정보를 얻는 게 목적

β분포 갱신 · 벨만 방정식 갱신이 모두 여기

추론 모드

  • 더 이상 배우지 않는다 — 학습된 정책만 실행
  • 매 상태에서 가장 좋은 행동만 고름 (활용 · exploitation)
  • 실전 배포 단계

학습 끝난 Q표에서 argmax만 하면 끝

탐험 vs 활용 (Exploration–Exploitation Trade-off)

새 식당을 도전할까(탐험), 맛집이 확실한 곳을 갈까(활용)? — 강화학습의 영원한 딜레마.

import numpy as np
import matplotlib.pyplot as plt

print("numpy :", np.__version__)

# 앞으로 쓸 베타분포 미리보기
x = np.linspace(0, 1, 200)
for a, b in [(1,1), (5,2), (2,8)]:
    plt.plot(x, x**(a-1) * (1-x)**(b-1), label=f"Beta(a={a}, b={b})")
plt.legend(); plt.title("Beta distribution"); plt.show()
