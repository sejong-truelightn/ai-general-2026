## 실습 진행 방법

1. 위 Colab 배지를 눌러 노트북을 엽니다.
2. `파일 → Drive에 사본 저장`으로 내 사본을 만듭니다. (사본을 만들지 않으면 작업이 저장되지 않습니다)
3. 셀을 **위에서부터 순서대로** `Shift + Enter`로 실행합니다.
4. `여기를_채우세요` 라고 적힌 곳을 직접 채웁니다. 바로 아래 셀의 검증이 통과하면 정답입니다.

> 실행이 꼬였다면 `런타임 → 런타임 초기화 후 모두 실행`으로 처음부터 다시 돌리면 됩니다.
